# 作戦

`vr strategy` の数字から、いつ止まるか、前後の車のストップにどう応じるかを決める。

## 読み方

| 行                                    | 意味                                                                                                                  |
| ------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| `fade per lap (tyres less fuel)`      | 1 周ごとのタイムの落ち。燃料が軽くなる分を差し引いた実測。`used` が計算に使う値、`own` は自車、`field` は他車の中央値 |
| `new tyres -0.90s at 3 stops`         | このレースでストップした車の、直前と直後のペース差                                                                    |
| `a stop costs 25.1s (field, 4 stops)` | ストップ 1 回の損失。出どころは `own`（自車）・`field`（他車）・`earlier sessions`（同じコースの過去）                |
| `fuel window for a single stop`       | 1 回の給油で届く、止まれる周の範囲                                                                                    |
| `plans`                               | 止まる周（その周の終わり）と、最速案からの遅れ                                                                        |
| `stopping now rejoins P6 ... TRAFFIC` | この周で入った場合の復帰位置と、前後の車。`TRAFFIC` は 2.5 秒以内に車                                                 |
| `net`                                 | 同じ回数止まった後の差。片方だけ止まっているときは、見た目の差ではなくこれで判断する                                  |
| `undercut gains +1.8/+3.6...`         | 先に入り、相手が 1・2・3・4 周遅れて入った場合の稼ぎ。`enough after 2` なら 2 周で逆転                                |
| `its stop gains`                      | 後ろの車が先に入った場合の、相手の稼ぎ。`passes after 2` なら 2 周以内に応じないと抜かれる                            |
| `overcut after 3 laps`                | 前の車が先に入ったとき、引っ張れば前に出る周数                                                                        |
| `calls`                               | 今、判断が要ること                                                                                                    |
| `no plan yet, missing: ...`           | 足りないデータ。作戦を言い切らず、何を待っているかを伝える                                                            |

数字は実測からの計算で、規則（必須ストップ、タイヤの使用義務）は含まない。規則は `vr info WeekendInfo` とドライバーから得る。

## 判断

1. 燃料で止まる必要があるかを先に見る（`fuel does not reach the end`、`fuel window`）
2. 最速案と次点の差を見る。2 秒以内なら、前後の車と戻る位置で決める
3. 後ろの車の `passes after` が 1〜2 なら、先に入られる前に入るか、入られた次の周に応じる
4. 前の車の `enough after` が 1〜2 なら、アンダーカットを提案する。戻る位置が `TRAFFIC` なら見送る
5. タイムの落ちが小さい（`used` が 0.05 未満）か、新品で速くならないなら、アンダーカットは効かない。引っ張る
6. コーション中は損失が減る。予定が近ければ入る
7. 雨と路面が変わるときは、`vr brief` の `tyres in the class`（他車がどのタイヤで何秒か）と `vr strategy` の `other tyres`（何周で元が取れるか、`worth changing now`）で替える周を決める。替えた車がまだいなければ、雨の傾向（`easing`、`stops in about N min`）から決める。止む時刻はゲームの予報ではなく今の弱まり方での目安

## 言い方

- 提案は、行動・理由の数字・期限の順に 1〜2 文:「次の周ボックス。Hart が 2.0 後ろ、先に入られると 1.8 稼がれる。」
- 応じる:「Hart が入った。net 3.0、2 周以内に入れば前を守れる。」
- 待つ:「まだ入らない。落ちは毎周コンマ 15、最適は 15 周目、今入ると Rossi の後ろで詰まる。」
- 言い切れない:「まだ誰も止まってなくて、ピットの損失が分からない。燃料は 12 周目まで。」
