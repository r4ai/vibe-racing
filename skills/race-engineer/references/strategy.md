# レース戦略・ピット判断

`vr strategy` の実測データから、ピット時期・前後への対応・タイヤ交換の判断を一つに決める。
規則（必須ストップ・タイヤ使用義務）は自動計算に含まれないため、`vr info WeekendInfo` とドライバーの発言で補う。

## 出力の読み方

| 行                                    | 意味                                                                                               |
| ------------------------------------- | -------------------------------------------------------------------------------------------------- |
| `fade per lap (tyres less fuel)`      | 燃料減を差し引いた 1 周ごとのタイムの落ち（デグラ）。`used` が計算値、`own` が自車、`field` が他車 |
| `new tyres -0.90s at 3 stops`         | ピット前後の新品タイヤのゲイン                                                                     |
| `a stop costs 25.1s (field, 4 stops)` | ピット 1 回の損失（`own`・`field`・`earlier sessions` の順で採用）                                 |
| `fuel window for a single stop`       | 1 ストップで完走できるピット周の範囲                                                               |
| `plans`                               | 止まる周（その周の終わり）と最速案からの遅れ                                                       |
| `stopping now rejoins P6 ... TRAFFIC` | 今入った場合の復帰位置と前後の車。`TRAFFIC` は 2.5 秒以内に他車あり                                |
| `net`                                 | 同じストップ回数に揃えた実質差。ピット回数が違う相手とは見た目の差ではなく `net` で比べる          |
| `undercut gains +1.8/+3.6...`         | 先に入った場合の 1〜4 周でのゲイン。`enough after 2` なら 2 周で逆転可能                           |
| `its stop gains`                      | 後ろが先に入った場合の相手のゲイン。`passes after 2` なら 2 周以内にカバーしないと抜かれる         |
| `overcut after 3 laps`                | 前が先に入ったとき、引っ張れば前に出られる周数                                                     |
| `other tyres`                         | ドライ／ウェット切替で何周で元が取れるか（`worth changing now` / `not worth it before the end`）   |
| `no plan yet, missing: ...`           | 計算に足りない要素。断定せず、何を待っているかを短く伝える                                         |

## 判断の優先順位

1. **燃料の制約**: `fuel does not reach the end` と `fuel window` を最優先で確認する
2. **プラン差と復帰位置**: 最速案と次点の差が 2 秒以内なら、前後との駆け引きと `rejoin_now`（クリアエアか `TRAFFIC` か）で決める
3. **アンダーカット防衛**: 後ろの `passes after` が 1〜2 なら、先に入られる前に先手を打つか、入られた次の周でカバーする
4. **アンダーカット攻撃**: 前の `enough after` が 1〜2 なら仕掛ける。ただし復帰位置が `TRAFFIC` なら見送る
5. **デグラが小さいとき**: `fade` が 0.05 秒未満、または新品ゲインが小さければアンダーカットは効かない。引っ張ってオーバーカットや燃料節約を優先する
6. **コーション／SC**: ピットロスが減るため、予定が近ければ即座に入る
7. **雨とタイヤクロスオーバー**: `vr brief` の `tyres in the class`（他車のコンパウンド別ペース）と `vr strategy` の `other tyres` で判断する。まだ替えた車がいなければ、雨量の増減（`rising` / `easing`、`stops in about N min`）から決める

## 無線での伝え方

戦略の回答には必ず **結論（入る周・ステイアウト） ＋ 決め手の数字 1 つ（デグラ・ピットロス・燃料の持ち・前後差・復帰位置）** を添える。

- **先制・提案**: 「次の周ボックスしよう。後ろと 2 秒、先に入られると 1.8 秒稼がれる。」
- **カバー**: 「後ろの 9 号車が入った。実質 3 秒差、2 周以内に入れば前を守れる。」
- **ステイアウト**: 「ステイアウト、予定は 15 周目だ。落ちは毎周コンマ 15、今入るとトラフィックに詰まる。」
- **データ不足**: 「まだ誰も止まってなくてピットロスが読めない。燃料は 12 周目まで持つ、もう少し様子を見よう。」
