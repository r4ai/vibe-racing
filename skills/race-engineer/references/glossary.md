# レース・テレメトリ用語集

- **gap / ギャップ**: 2 台の時間差。ある地点を前の車が通過してから後ろの車が通過するまでの秒差
- **interval / インターバル**: 順位表で 1 つ前の車との差
- **trend / 推移**: コントロールライン通過ごとに記録したギャップの変化量（秒/周）。負なら差が縮小
- **relative / nearby**: 順位に関係なくコース上で物理的に近い車（周回遅れ・他クラスを含む）
- **stint / スティント**: ピットアウトから次のピットインまでの連続走行区間
- **in-lap / out-lap**: ピットに入る周／ピットから出た周（平均ペース・燃費の母集団から除外）
- **clean lap**: ピット通過も黄旗も無い通常の周
- **fade / デグラ（タレ）**: 1 周ごとのタイム低下量。燃料が軽くなる効果を除いたタイヤ劣化の実測
- **pit loss / ピットロス**: ピット 1 回で失う総時間（走り続けた場合との差）
- **アンダーカット**: 相手より先にピットに入り、新品タイヤの速さで逆転する作戦
- **オーバーカット**: 相手が入った後もコース上に残り、引っ張って前に出る作戦
- **net の差（実質差）**: 双方が同じピット回数に揃った後のタイム差
- **リフコ（リフト＆コースト）**: ブレーキング手前で早めにアクセルを戻して転がす燃費・温度セーブ走法
- **ショートシフト**: 通常より低い回転で早めにシフトアップし、燃費やリアのトラクションを稼ぐ走法
- **トレイルブレーキ**: コーナーへ向きを変えながらブレーキを徐々に抜いてフロント荷重を残す操作
- **BB / ブレーキバイアス**: 制動力の前後配分。数値が大きいほど前寄り
- **TC / ABS**: トラクションコントロール（空転制御）／アンチロックブレーキ（ロック制御）。数値と効きの向きは車種による
- **OTS / P2P**: オーバーテイクシステム（プッシュトゥパス）。残量・作動状況はゲーム出力に従う
- **rake / レーキ**: リア車高とフロント車高の差（リア − フロント）
- **OMI / IMO**: タイヤ表面温度の並び（外・中・内／内・中・外）
- **incident (x)**: iRacing のインシデントポイント（`2x`・`4x` 等）
- **fast repair / tow**: 即時修理の権利／自走不能時にピットへ運ばれること
- **フラッグ（読み上げはカタカナ表記を使う）**
  - `green`: グリーン（通常走行）
  - `yellow` / `yellow waving`: イエロー（局所黄旗、追い越し禁止）
  - `full course caution`: フルコースコーション（セーフティカー）
  - `blue`: ブルーフラッグ（速い車・周回差の車に譲る）
  - `white` / `chequered`: ファイナルラップ／チェッカー
  - `black`: ブラックフラッグ（ペナルティ消化のためピットイン）
  - `meatball (repair)`: ミートボールフラッグ（重大損傷、修理のため要ピット）
  - `black and white`: 白黒旗（ドライビングへの警告）
  - `debris` / `slow car`: デブリ（落下物注意）／前に遅い車
  - `one lap to green` / `disqualify`: 次の周リスタート／失格
