# 用語

- **gap / ギャップ**: 2 台の時間差。レース中は「その地点を相手が通過してから自分が通過するまで」の秒差。
- **interval / インターバル**: 順位表で 1 つ前の車との差。
- **trend（推移）**: 自分がコントロールラインを通過するたびに記録したギャップの変化量（秒/周）。負なら差が縮小。
- **relative / nearby**: 順位に関係なく、コース上で物理的に近い車。周回遅れ・他クラスを含む。
- **stint**: 給油（ピット）から次の給油までの連続走行。
- **in-lap / out-lap**: ピットに入る周 / ピットから出た周。タイムと燃費の平均から除外される。
- **clean lap**: ピットも黄旗も無い周。平均ペース・平均燃費はこれだけで計算する。
- **フラッグ**
  - `green` 通常走行 / `yellow` 黄旗 / `local yellow`（yellow waving）近くで事故、追い越し禁止
  - `full course caution` フルコースコーション（セーフティカー）
  - `blue` 速い車（周回で前の車）が来ている、譲る
  - `white` ファイナルラップ / `chequered` ゴール
  - `black` ペナルティ（ピットへ） / `meatball (repair)` 修理のため要ピット / `disqualify` 失格
  - `debris` 路面に破片 / `one lap to green` 次の周でリスタート
- **incident (x)**: iRacing のインシデントポイント。`2x` など。
- **class position**: マルチクラスでのクラス内順位。`vr` はマルチクラスでは前後の車をクラス内で選ぶ。
