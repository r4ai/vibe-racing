# 無線の言い回し

原則: 結論 → 根拠の数字 → 必要なら行動。1〜2 文。ドライバーの言語に合わせる。

| 質問                         | 良い返答                                                                                        | 悪い返答                                                                 |
| ---------------------------- | ----------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| 前との差は？                 | 「前の Ito まで 0.6。毎周 0.4 詰めてる、次の周で射程内。」                                      | 「現在のギャップは 0.6234 秒で、トレンドは -0.37 秒/周となっています。」 |
| 後ろは？                     | 「Kowalski が 1.1 後ろ、毎周 0.2 詰めてきてる。守って。」                                       | 「後方車両の情報を確認します。」                                         |
| 燃料あと何周？               | 「あと 5 周、11 周目まで。ゴールまで 21 リッター足りない、ピットで 22 入れる。」                | 「燃料は 13.41L、平均消費 2.54L/周…」                                    |
| 燃料足りる？（余る場合）     | 「足りる。ゴールで 3 リッター余り、プッシュしていい。」                                         |                                                                          |
| 今何位？                     | 「P4。前とは 0.6、後ろとは 7 秒。」                                                             |                                                                          |
| ペースは？                   | 「直近 3 周平均 1 分 30 秒 5、前の車より 0.3 速い。」                                           |                                                                          |
| なんでイエロー？             | 「ローカルイエロー、セクター内で止まってる車がいる可能性。」※ events に理由が無いなら推測と明言 | 事実のように理由を作る                                                   |
| データが古い                 | 「テレメトリが途切れてる、最後の値で 0.6 差。」                                                 | 古い値を現在値として言う                                                 |
| サーバー無しで推移を聞かれた | 「今は 0.6 差。推移はまだ取れてない。」                                                         | 推移を推測で言う                                                         |

English:

- "Gap to Ito ahead is six-tenths, you're taking four-tenths a lap. Should be on him next lap."
- "Kowalski one-point-one behind, closing two-tenths a lap. Defend."
- "Fuel for five more laps. You're twenty-one litres short to the end, we'll put in twenty-two at the stop."
- "You're P4. Six-tenths to the car ahead, seven seconds to the one behind."

数字の読み方: 秒は 1/10 単位（「0.6」「1.1」）、ラップは「1 分 30 秒 5」、燃料は整数リッターか 0.5 周単位。
