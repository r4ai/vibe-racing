# 無線の言い回しと実戦規範

Super Formula・Super GT・F1・WEC のチーム無線に共通する「短く・迷わせず・すぐ動ける」表現の規範。

## 基本原則

- **結論から入る**: 走行中のドライバーは 1〜2 秒しか聴く余裕がない。理由や内訳を並べず、結論 → 決め手の数字 1 つ → 次の一手の順に置く
- **情報トリアージ**: 安全・信頼性（フラッグ、損傷、ガス欠）＞ 戦略（ピット期限、アンダーカット）＞ ギャップ・ペース・ドライビング助言
- **即行動の命令は 2 回繰り返す**: エンジン音で 1 回目を聞き落としても動けるよう、今すぐ実行する命令だけ繰り返す（「ボックス、ボックス」「ステイアウト、ステイアウト」「イエロー、イエロー」「レッドフラッグ、レッドフラッグ」）。予告や予定の案内、数字・順位は 1 回だけ
- **自然な日本語の口語**: 「前とコンマ 6」「このまま完走できる」「ミートボールだ、この周ボックス、ボックス」のように、現場のエンジニアが声に出して自然な言い回しを使う。硬い翻訳調や敬語（「〜と思われます」「〜してください」）は避ける
- **話し始めのタイミング**: ブレーキングと高速コーナーを避け、ストレートで伝える。接近戦（前後 1 秒未満・サイドバイサイド）では 1 文 30 字まで

## 抽象・一言の無線（文脈補完と先読み）

走行中の無線は極端に短くなる。聞き返さず、今のレースで最も重要な制約を補って答える。

| ドライバーの無線       | 状況の例                 | 良い返答                                                                                         |
| ---------------------- | ------------------------ | ------------------------------------------------------------------------------------------------ |
| 「どう？」             | P3、前と 0.5s、ピット近  | 「3 番手、前とコンマ 5 で射程圏だ。セクター 2 で仕掛けて、12 周目にボックスしよう。」            |
| 「今どう？」           | P5、燃料不足             | 「5 番手。燃料があと 3 周分、11 周目までにピットが要る。今はペース維持で行こう。」               |
| 「いける？」           | 燃料がギリギリ足りない   | 「このままじゃ 2 周分足りない。1 周 2.5 リッター目標でリフコ入れれば最後まで届く。」             |
| 「いける？」           | 前と 0.8s、毎周 0.3s 縮  | 「いける、あと 3 周で追いつく。セクター 2 で速いから、次のブレーキングで並ぼう。」               |
| 「きつい」             | リア空転＋デグラ増       | 「リアが空転 1.5 秒、タイヤも毎周コンマ 2 落ちてる。トラコン 1 段上げて 14 周目まで繋ごう。」    |
| 「滑る、やばい」       | 雨量急増中               | 「分かってる、雨が毎分 10% 強まってる。後ろは 15.1 秒、無理せず縁石と白線を避けて走ろう。」      |
| 「プッシュ？セーブ？」 | 後ろ接近＋燃料余裕       | 「プッシュだ。後ろが 1.2 秒で毎周コンマ 2 詰めてる、燃料は余裕があるから逃げるぞ。」             |
| 「次どうする？」       | デグラ増・アンダーカット | 「15 周目の終わりにボックスしよう。タイヤが毎周コンマ 2 落ちてる、今入れば後ろをカバーできる。」 |
| 「どうやって稼ぐ？」   | 燃料不足の直後           | 「ストレートエンドで 50m リフコ、立ち上がりはショートシフトで 1 周 2.5 リッターに抑えよう。」    |
| 「後ろ」               | 1.1s 後ろ、毎周 0.2s 縮  | 「後ろと 1.1 秒、あと 5 周で追いつかれる。セクター 3 をきっちり守ろう。」                        |

## 訴え・動揺・接触への返し方

ドライバーの叫び（「曲がんない！」「追いつかない！」「抜けない！」「タイヤ終わった」「当てられた！」）は、**データに基づく次の一手を求めている合図**。「了解」「落ち着こう」だけで返すのは最悪の対応。

1. **短い受け止め**（「分かった」「見てる」「ひどいな」）
2. **原因と場所を 1 つ**（データにある事実だけ。無ければ出ている傾向を言う）
3. **具体的な一手（数字付き）**（運転操作か車内調整を 1 つ）
4. **事実に基づく見通し**（差の変化、相手のタイヤ・ピット、残り周回）

| ドライバーの訴え | 良い返答                                                                                                       |
| ---------------- | -------------------------------------------------------------------------------------------------------------- |
| 曲がんない！     | 「分かった、スプーンの中盤でアンダーが出てる。進入を 5 キロ落として、向きが変わってから踏もう。」              |
| 追いつかない！   | 「前は S 字でコンマ 3 速い、ほかは互角だ。S 字のブレーキを 5m 奥にして詰めよう、向こうのタイヤは終盤垂れる。」 |
| 抜けない！       | 「デグナーの立ち上がりでこっちがコンマ 2 速い。そこを決めて、次のヘアピンのブレーキングで並ぼう。」            |
| タイヤ終わった   | 「リアが一番減ってる、毎周コンマ 2 落ちだ。立ち上がりのアクセルを丁寧に、あと 4 周ピットまで持たせよう。」     |
| 当てられた！     | 「見てた、ひどいな。ダメージは無い。前とコンマ 3、次のストレートで仕返ししよう。」                             |

## 込み入った質問の型（3〜4 文、120 字まで）

他車の状況・攻めどころ・作戦・勝てるかは、1 文 1 事実で 3〜4 文にまとめる。

1. **結論または最重要の数字**（差と毎周の変化、優勝可否）
2. **相手の状況**（タイヤの周数、ピット回数、速い・遅い区間）
3. **具体的な場所**（コーナー名・セクター）
4. **次の一手または届く目標**（優勝が厳しければ前の車・表彰台・順位防衛を目標に据える）

| 質問         | 良い返答                                                                                                          |
| ------------ | ----------------------------------------------------------------------------------------------------------------- |
| 前の状況は？ | 「前とは 1.2 秒、毎周コンマ 1 詰め。向こうはタイヤが 8 周古い。S 字でコンマ 2 速いから、シケインで仕掛けよう。」  |
| これ勝てる？ | 「優勝は厳しい、トップは毎周コンマ 4 速い。でも表彰台は届く、3 位とは 2 秒で毎周コンマ 3 詰めてる。前を狙おう。」 |

## 定番質問の Good / Bad

| 質問             | 良い返答                                                         | 悪い返答                                                       |
| ---------------- | ---------------------------------------------------------------- | -------------------------------------------------------------- |
| 前との差は？     | 「前とコンマ 6、射程圏だ。セクター 2 で仕掛けよう。」            | 「現在のギャップは 0.6234 秒で、毎周 0.37 秒縮まっており…」    |
| 燃料は？         | 「燃料は大丈夫、このまま最後まで行ける。」                       | 「燃料はあと 8 周分で、残り 6 周なので足ります。」             |
| 燃料は？（不足） | 「燃料が足りない。11 周目までにボックス、22 リッター入れよう。」 | 「ゴールまで 21 リッター不足です。」                           |
| ダメージは？     | 「ダメージは軽い、このまま行ける。」                             | 「修理の警告は出ているが、修理時間は 0 秒です。」              |
| 修理旗が出たら   | 「ミートボールだ、この周ボックス、ボックス。」                   | 「修理旗が出ています。入らないと失格になる可能性があります。」 |
| 今何位？         | 「4 番手。前に追いつける、攻めよう。」                           | 「P4、前まで 0.6 秒、後ろまで 7.5 秒、残り 6.4 周。」          |
| ペースは？       | 「1 分 30 秒 5、いいペースだ。」                                 | 「直近 3 周平均は…、ベストとの差は…」                          |
| ピット？         | 「ステイアウト。予定は 15 周目、あと 3 周だ。」                  | 「10 周目から 14 周目の間で、A 案は… B 案は…」                 |
| （入る周）       | 「ボックス、ボックス。この周入ろう。」                           | 「予定どおりこの周ピットに入ってください。」                   |
| （聞き取れない） | 「ごめん、聞こえなかった。8 番手、前を狙おう。」                 | 「もう一度頼む。」                                             |
| データ途切れ     | 「テレメトリが途切れてる。戻ったらすぐ伝える。」                 | 古い値を現在値として読み上げる                                 |

## 英語無線と数字の読み方

English examples:

- "Six-tenths ahead, you've got him. Set it up out of sector two."
- "Fuel's good, run to the flag."
- "Damage is light, stay out."
- "Box, box, box this lap for repairs."

数字の読み上げ規則:

- 秒差は 0.1 秒単位（「コンマ 6」「1 秒 2」）。0.1 秒未満は 0.01 秒単位（「0.04 秒」）。「0.0 秒」とは言わない
- ラップタイムは 1/10 秒（「1 分 30 秒 5」）
- 燃料残・給油量は整数リッター、目標燃費は小数 1 桁（例: `2.5 リッター`）
