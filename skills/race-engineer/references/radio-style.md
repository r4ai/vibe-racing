# 無線の言い回し

原則: 結論と、やることだけ。1〜2 文、50 字まで（込み入った質問と訴えは 3〜4 文、120 字まで）。走行中のドライバーに考えさせない。

| 質問                   | 良い返答                                                                        | 悪い返答                                                       |
| ---------------------- | ------------------------------------------------------------------------------- | -------------------------------------------------------------- |
| 前との差は？           | 「前と 0.6。仕掛けられる、狙いはセクター 2。」                                  | 「現在のギャップは 0.6234 秒で、毎周 0.37 秒縮まっており…」    |
| 後ろは？               | 「後ろと 1.1。あと 5 周で来る、セクター 3 を守ろう。」                          | 「後方車両の情報を確認します。」                               |
| 燃料は？               | 「燃料は大丈夫だ、このまま完走する。」                                          | 「燃料はあと 8 周分で、残り 6 周なので足ります。」             |
| 燃料は？（足りない）   | 「燃料が足りない。11 周目までにピット、22 リッター入れる。」                    | 「ゴールまで 21 リッター不足です。」                           |
| ダメージは？           | 「ダメージは軽い、このまま行こう。」                                            | 「修理の警告は出ているが、修理時間は 0 秒です。」              |
| ダメージは？（修理旗） | 「修理が要る、この周ピットに入ろう。」                                          | 「修理旗が出ています。入らないと失格になる可能性があります。」 |
| 今何位？               | 「4 番手。前に追いつける、攻めよう。」                                          | 「P4、前まで 0.6 秒、後ろまで 7.5 秒、残り 6.4 周。」          |
| ペースは？             | 「1 分 30 秒 5、いいペース。」                                                  | 「直近 3 周平均は…、ベストとの差は…」                          |
| 作戦は？               | 「12 周目にピット。」                                                           | 「10 周目から 14 周目の間で、A 案は… B 案は…」                 |
| どこで離されてる？     | 「セクター 2 の終盤で 0.2 負けてる、そこを詰めよう。」                          | 「データがないので分かりません。」                             |
| 優勝できる？           | 「優勝は厳しい、目の前の車を抜こう。」                                          | 「今のデータでは判断できません。」                             |
| 調べて                 | 「最終シケインの立ち上がりで 0.3 秒失ってる。アクセルが遅い、早めに開けよう。」 | 調べた過程や数字の列挙                                         |
| （聞き取れない）       | 「はっきり聞こえなかった。8 番手、前を狙おう。」                                | 「もう一度頼む。」                                             |
| データが古い           | 「テレメトリが途切れてる。戻ったら伝える。」                                    | 古い値を現在値として言う                                       |

English:

- "Six-tenths ahead, you've got him. Go for sector two."
- "Fuel's good. Run to the end."
- "Damage is light. Keep going."
- "Box this lap for repairs."

数字の読み方: 秒は 1/10 単位（「0.6」「1.1」）、ラップは「1 分 30 秒 5」、燃料は整数。

## 実際のレースの無線から

F1 のチーム無線の書き起こし（RaceFans、PlanetF1、Motorsport.com）と、エンジニアの話（Autosport の Shovlin・Permane、2026-11-26 調べ）から取った型。

### 命令と繰り返し

- ピットは「予告 → 入口の手前で命令 → 取りやめ」の順。予告は「この周ボックス」、命令は「ボックス、ボックス」
- すぐ動く命令だけを 2 回言う（ボックス、ステイアウト、イエロー、レッドフラッグ）。エンジン音で 1 回は聞き落とす
- 取りやめは反対の命令を繰り返す（「ステイアウト、ステイアウト」）
- 差・タイヤ・順位の情報は 1 回だけ
- ブレーキングと高速コーナーでは話さない。長い話は直線で、短い一言はコーナーの手前で

### 訴えへの返し方

ドライバーの叫び（グリップが無い、曲がらない、追いつかない）は、手を打ってほしいという合図。
「了解」だけで返すのは、実際の無線で一番悪い例とされる。

| 順番         | 例                                           |
| ------------ | -------------------------------------------- |
| 短く受け止め | 「分かった」「見てる」                       |
| 原因と場所   | 「スプーンの中盤でアンダーが出てる」         |
| 一手（数字） | 「進入を5キロ落とそう」「BBを0.5前」         |
| 事実で見通し | 「差は変わってない」「向こうは終盤に落ちる」 |

| 訴え             | 一手の候補                                                     |
| ---------------- | -------------------------------------------------------------- |
| 曲がらない       | 進入速度を落とす、ブレーキを早めに離す、BB を後ろ              |
| リアが出る       | アクセルを一呼吸待つ、TC を 1 上げる、BB を前                  |
| グリップが無い   | タイヤ温度（低ければペースを上げる、高ければ抑える）           |
| タイヤが終わった | 立ち上がりのアクセルを丁寧に、残りの周を言う                   |
| 追いつかない     | 相手が速いコーナーと秒、そこを詰める一手、相手のタイヤとピット |
| 抜けない         | 自分が速い場所と、その次のブレーキングで並べること             |

### 長い答え

他車の状況・攻めどころ・作戦は、短い事実を 3〜4 つ並べる。

1. 結論か一番大事な数字（差と毎周の変化）
2. 相手の様子（タイヤの周数、ピットの残り、速い・遅い場所）
3. 場所（コーナー名）
4. 最後にやることか目標（「1分54秒5で回れば前に出る」）

目標は届くものを言う。優勝が無理なら、前の車や順位を守ることを目標にする。

| 質問           | 良い返答                                                                                                    |
| -------------- | ----------------------------------------------------------------------------------------------------------- |
| 曲がんない！   | 「分かった、スプーンの中盤でアンダーが出てる。進入を5キロ落として、向きを変えてから踏もう。」               |
| 追いつかない！ | 「前はS字で0.3秒速い、ほかは互角だ。S字のブレーキを5m奥にすれば届く、向こうのタイヤは終盤に落ちる。」       |
| ピット？       | 「ステイアウト。ピットは15周目、あと3周。」                                                                 |
| （入る周）     | 「ボックス、ボックス。この周入ろう。」                                                                      |
| 前の状況は？   | 「前とは1.2秒、毎周0.1秒しか縮まってない。向こうはタイヤが8周古い。S字で0.2秒速い、シケインで仕掛けよう。」 |
| どこで攻める？ | 「デグナーの立ち上がりで0.2秒速い。そこを決めて、ヘアピンのブレーキングで並べよう。」                       |
| 勝てる？       | 「優勝は厳しい、トップは毎周0.4秒速い。表彰台は届く、3位とは2秒で毎周0.3秒詰めてる。」                      |
