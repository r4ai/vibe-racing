# セットアップの提案

ドライバーの訴え（言葉）と `vr handling`（データ）を突き合わせ、変更を 1 つだけ提案する。

## 手順

1. 訴えを「どこで」「何が」に分ける（進入・中間・脱出、低速・高速、アンダー・オーバー・ロック・空転）。分からなければ 1 回だけ聞き返す
2. `vr handling` で裏を取る。訴えと一致すれば提案、食い違えば食い違いを伝える
3. 走行中は、車内で変えられる項目（`settings in the car`）だけを提案。ガレージの項目は「次のセッションで」と添える
4. 一度に 1 項目・1 段階。向きと量を言う（「BB を 0.5 前、57.7 へ」）
5. 変更後 2〜3 周で `vr handling` と `vr laps --last 5` を見て、残す・戻す・次を決める。変更の履歴は `changed while driving` にある

## データの読み方

`vr handling` の値は 1 周あたりの秒数。入力と車の動きからの推定で、測定値ではない。

| 項目         | 意味                                               |
| ------------ | -------------------------------------------------- |
| understeer   | 限界付近で、舵を足しても曲がりが増えなかった時間   |
| oversteer    | カウンターを当てていた時間                         |
| wheelspin    | エンジン回転がギアと車速より高かった時間           |
| rear locking | 制動中、エンジン回転がギアと車速より低かった時間   |
| ABS          | ABS が働いていた時間                               |
| where        | 1 周を 20 等分した区間。`15-20%` は周回の 15〜20 % |

- 限界で走れば、どの値も 0 にはならない。同じ車・同じセッションの周どうしで比べる
- `laps_sampled` が 2 未満なら、データからの提案はしない
- クラッシュやスピンの周は値が跳ねる。`vr events` のインシデントと照合して除く
- iRacing のタイヤの温度と溝は、ピットで止まった時点の値

## 症状と打ち手

走行中に変えられる項目を先に試す。その車に無い項目は提案しない。

| 症状                     | 車内                                       | ピット・ガレージ                       |
| ------------------------ | ------------------------------------------ | -------------------------------------- |
| 進入アンダー             | BB を後ろへ 0.5                            | フロントの車高・ダンパー、フロント羽根 |
| 進入オーバー・後輪ロック | BB を前へ 0.5〜1.0、エンジンブレーキを弱く | コーストデフを強く、リア車高           |
| 前輪ロック               | BB を後ろへ、ABS を強く                    | ブレーキパッド                         |
| 中間アンダー             | フロント ARB を柔らかく                    | フロント羽根を増、フロント内圧を下げる |
| 中間オーバー             | リア ARB を柔らかく                        | リア羽根を増                           |
| 脱出アンダー             | TC を弱く                                  | リアを固く、デフのパワー側を弱く       |
| 脱出オーバー・空転       | TC を強く、スロットルマップを穏やかに      | リア ARB を柔らかく、デフのプリロード  |
| 高速だけアンダー         | —                                          | フロント羽根を増                       |
| 高速だけオーバー         | —                                          | リア羽根を増、リア車高を下げる         |
| 後半だけ苦しい           | TC を強く、BB を調整                       | 内圧、キャンバー                       |

- BB（`brake_bias`）は数値が大きいほど前寄り
- TC・ABS・マップは、数値の大小と効きの向きが車種で違う。「1 段強く・弱く」と言い、向きに自信が無ければその場で変化を聞く
- タイヤ: 中央が高温なら内圧を下げ、低温なら上げる。内側が外側より 15 ℃ 以上高ければキャンバーを減らす
- 変更の副作用（`risk`）は、聞かれたとき、または安全に関わるときだけ一言

## 言い方

- 「フロント入らない」→「中間で毎周 3 秒アンダー出てる。フロント ARB は車内で動かせない。まず BB を 0.5 後ろ、56.8 へ。」
- 「立ち上がりで滑る」→「脱出のカウンターが毎周 1 秒、空転も出てる。TC を 1 段強く。2 周で見る。」
- 「さっきの変更どう？」→「BB を下げてから進入アンダーが 0.6 から 0.2、ラップは 0.2 速い。このまま。」
- データが無い:「まだ 1 周分しか無い、あと 1 周走って。今の感触だと進入と脱出、どっち？」
