# 挙動診断とセットアップ提案

ドライバーのフィーリング（訴え）とテレメトリを突き合わせ、**一度に 1 項目だけ**、物理的な理由を添えて提案する。

## データの使い分け

| 場面               | コマンド                           | 得られる情報                                            |
| ------------------ | ---------------------------------- | ------------------------------------------------------- |
| 走行中             | `vr handling`                      | 挙動傾向（秒/周）、場所・局面、速度域別、調整履歴、提案 |
| 走行後・ガレージ   | `vr sessions analyse`              | 上に加え、四輪の実測、ガレージ項目と現在値付きの打ち手  |
| 別セットとの比較   | `vr sessions analyse` の `against` | 変更項目ごとのラップ・バランス差                        |
| 現在のセットアップ | `vr setup`                         | ガレージの全項目と車内調整の現在値                      |

- `vr handling` は操作と車両挙動からの推定値。限界走行では 0 にならないため、同セッション内の比較で読む
- `laps_sampled < 2` のときはデータからの提案を行わない。スピン・接触の周は `vr events` と照合して除外する
- 四輪実測（`measured at the wheels`）は iRacing では走行後の `.ibt` から自動取込、AMS2 では走行中もライブ取得

## 提案の手順

1. **訴えの分解**: 局面（進入・中盤・脱出）× 速度域（低・中・高）× 症状（アンダー・オーバー・ロック・空転）に分ける。場所の言及が無ければ `brief` の `in` / `last corner` を補う
2. **データ照合**: 訴えと一致すれば提案する。食い違えば「リアは出てない、出てるのは S 字の中盤アンダーだ」と事実を伝えてから一手を出す
3. **走行中は車内調整のみ**: `settings in the car` にある項目だけを提案し、ガレージ項目は「次のセッションで」と添える
4. **量の根拠**: `vr handling` の提案に `to 56.5` のように行き先があればそれを使う（その車の刻みとセッション内効果から算出済み）。無ければ「1 段」と言い、根拠の無い数字を作らない。`leave it` は逆効果だった履歴があるため勧めない
5. **物理を一言**: 「減速で荷重が前に移るからリアが先にロックする」のように理由を一言だけ添える
6. **効果検証**: 変更から 2〜3 周後に `what the changes did` で改善を数字で確認し、残す・戻す・次を決める

## 四輪実測の読み方

| 項目                            | 判断基準                                                                                |
| ------------------------------- | --------------------------------------------------------------------------------------- |
| `locking s/lap`                 | 制動時の車輪ロック。前が多ければ BB を後ろ、後ろが多ければ前。両方なら踏み方            |
| `wheelspin s/lap`               | 加速時の空転。片輪だけなら LSD、両輪なら足回り・ウイングまたはスロットル操作            |
| `ride height` / `rake`          | 速度域ごとの車高変化＝ダウンフォースの沈み込み。`rake` はリア − フロント                |
| `touching the ground`           | 2 mm 以下の底付き。0.4 秒/周以上ならその軸を上げるかヒーブ／サードを硬く                |
| `LF loaded: outer/middle/inner` | 内 − 外が 9 ℃ 超ならキャンバー減、−1 ℃ 未満なら増。中央が両端平均より ±3 ℃ なら内圧調整 |
| `damper %`                      | 遅い動き（操作）／速い動き（縁石・段差）。左右合計の偏り（1.4 倍超）を確認              |
| `by corner speed`               | 低速だけなら足回り（ARB・デフ・バネ）、高速だけなら空力（ウイング・車高）、全域なら両方 |

## 症状と打ち手

その車に存在しない項目は提案しない。

| 症状                     | 車内調整（走行中）                   | ピット・ガレージ（次セッション）       |
| ------------------------ | ------------------------------------ | -------------------------------------- |
| 進入アンダー             | BB を 1 段後ろ                       | フロント車高・ダンパー、フロント羽根   |
| 進入オーバー・リアロック | BB を 1 段前、エンジンブレーキ弱め   | コーストデフ強め、リア車高             |
| 前輪ロック               | BB を後ろ、ABS 強め                  | ブレーキパッド                         |
| 中盤アンダー             | フロント ARB を 1 段柔らかく         | フロント羽根増、フロント内圧下げ       |
| 中盤オーバー             | リア ARB を 1 段柔らかく             | リア羽根増                             |
| 脱出アンダー             | 向きが変わってから踏む（運転）       | リアを硬く、パワーデフ弱め             |
| 脱出オーバー・空転       | トラコン強め、スロットルマップ穏やか | リア ARB 柔らかく、デフプリロード      |
| 高速だけアンダー         | —                                    | フロント羽根増（車高・レーキは下参照） |
| 高速だけオーバー         | —                                    | リア羽根増（車高・レーキは下参照）     |
| 後半だけ苦しい           | トラコン強め、BB 微調整              | 内圧、キャンバー                       |

- **BB（ブレーキバイアス）**: 数値が大きいほど前寄り
- **TC（トラコン）**: 空転に効く。空転が無い脱出オーバー／アンダーは TC ではなく踏み方かデフ・リア剛性
- **TC・ABS・マップの向き**: 数値の大小と効きの強弱は車種で異なるため「1 段強く・弱く」で伝える
- **レーキ・車高**: フロア構造で効き方が車種ごとに異なる。速度域別車高と過去比較（`vr sessions compare`）の根拠があるときだけ向きを言い、無ければ「次のセッションで 1 段試して比べよう」と伝える
- **副作用（`risk`）**: 聞かれたとき、または安全に関わるときだけ一言添える

## 無線での言い方

- 「フロント入らない」→「中速で毎周 2 秒アンダー、高速は大丈夫。フロント ARB を 1 段柔らかくしよう。車内で無理なら次セッションだ。」
- 「立ち上がりで滑る」→「リア両輪が毎周 2.7 秒空転してる。トラコン 1 段強くして、2 周様子を見よう。」
- 「ブレーキで止まらない」→「右前だけ毎周コンマ 5 ロック、左は出てない。BB は動かさず、ブレーキの抜きを少し早めに。」
- 「さっきの変更どう？」→「BB を下げてから進入アンダーがコンマ 4 減って、ラップもコンマ 2 速い。このまま行こう。」
