# セットアップの提案

ドライバーの訴え（言葉）とデータを突き合わせ、変更を 1 つだけ提案する。

## どのデータを見るか

| 場面                     | コマンド                           | 分かること                                               |
| ------------------------ | ---------------------------------- | -------------------------------------------------------- |
| 走行中                   | `vr handling`                      | 傾向（秒/周）、場所、速度域別、車内の変更の結果、変更案  |
| 走行後・ガレージ         | `vr sessions analyse`              | 上に加え、四輪の実測、ガレージの項目と現在値つきの打ち手 |
| 別のセットアップとの比較 | `vr sessions analyse` の `against` | 変えた項目と、ラップ・バランスの差                       |
| 項目の現在値             | `vr setup`                         | ガレージの全項目                                         |

- 四輪の実測（`measured at the wheels`）は、iRacing が走行後に残す記録ファイルから取る。走行を終えてしばらくすると自動で取り込まれる。走行中の値は直前の走行のもの。AMS2 は走行中の値をそのまま使う
- `vr handling` の値は入力と車の動きからの推定。限界で走れば 0 にならない。同じ車・同じセッションの周どうしで比べる
- `laps_sampled` が 2 未満なら、データからの提案はしない
- クラッシュやスピンの周は値が跳ねる。`vr events` のインシデントと照合して除く

## 手順

1. 訴えを「どこで」「何が」に分ける（進入・中間・脱出、低速・中速・高速、アンダー・オーバー・ロック・空転）。分からなければ 1 回だけ聞き返す
2. データで裏を取る。訴えと一致すれば提案、食い違えば食い違いを伝える
3. 走行中は、車内で変えられる項目（`settings in the car`）だけを提案。ガレージの項目は「次のセッションで」と添える
4. 一度に 1 項目。項目名・現在値・向き・行き先を言う（「BB を 56.5 まで前に」）。量は `vr handling` の提案の `to …` を使う。`to` はその車の刻み（ドライバーが回した最小の幅）と、このセッションで同じ項目を変えたときの効果から計算してある（3 段まで）。`to` が無ければ「1 段」と言い、量を作らない。`leave it` は、その向きに変えて悪くなった記録がある
5. 理由は物理で一言（減速で荷重が前に移るのでリアが先にロック、加速で荷重が後ろに移るのでフロントが逃げる、など）
6. 変更後 2〜3 周で `what the changes did` を見て、残す・戻す・次を決める

## 実測の読み方

| 項目                            | 意味と判断                                                                                              |
| ------------------------------- | ------------------------------------------------------------------------------------------------------- |
| `locking s/lap`                 | 制動中に車輪が車速より 12 % 以上遅い時間。前が長ければ BB を後ろ、後ろが長ければ前。両方なら踏み方      |
| `wheelspin s/lap`               | 加速中に 10 % 以上速い時間。片輪だけなら LSD、両輪なら脚と羽根、または踏み方                            |
| `brake pressure at the front`   | 実際の前の圧力配分                                                                                      |
| `ride height`                   | 直線での前後の高さ。速度域ごとの変化がダウンフォースによる沈み込み。`rake` は後ろ − 前                  |
| `touching the ground`           | 2 mm 以下まで沈んだ時間。0.4 秒以上なら、その軸を上げるかヒーブ・サードを硬く                           |
| `LF loaded: outer/middle/inner` | 荷重が乗ったときの表面温度。内 − 外が 9 ℃ を超えればキャンバーを減らし、−1 ℃ 未満なら増やす             |
| 同上の中央                      | 両端の平均より 3 ℃ 以上高ければ内圧を下げ、低ければ上げる                                               |
| `damper %`                      | リバウンド・バンプの遅い（操作）／速い（段差・縁石）動きの時間。左右の合計が 1.4 倍以上違えば減衰が偏る |
| `by corner speed`               | 低速だけなら脚（ARB・デフ・スプリング）、高速だけなら羽根と車高、全域なら両方                           |

- 打ち手（`findings`）は車のセットアップにある項目だけを、穏やかな順に挙げる。複数の打ち手が食い違う（ウイングを増やす・減らすなど）ときは、ドライバーの訴えに合う方を選ぶ
- 温度はコンパウンドと路温で変わる。絶対値ではなく、左右・内外の差を見る

## 症状と打ち手

走行中に変えられる項目を先に試す。その車に無い項目は提案しない。

| 症状                     | 車内                                   | ピット・ガレージ                       |
| ------------------------ | -------------------------------------- | -------------------------------------- |
| 進入アンダー             | BB を後ろへ 1 段                       | フロントの車高・ダンパー、フロント羽根 |
| 進入オーバー・後輪ロック | BB を前へ 1 段、エンジンブレーキを弱く | コーストデフを強く、リア車高           |
| 前輪ロック               | BB を後ろへ、ABS を強く                | ブレーキパッド                         |
| 中間アンダー             | フロント ARB を柔らかく                | フロント羽根を増、フロント内圧を下げる |
| 中間オーバー             | リア ARB を柔らかく                    | リア羽根を増                           |
| 脱出アンダー             | アクセルは向きが変わってから（運転）   | リアを固く、デフのパワー側を弱く       |
| 脱出オーバー・空転       | TC を強く、スロットルマップを穏やかに  | リア ARB を柔らかく、デフのプリロード  |
| 高速だけアンダー         | —                                      | フロント羽根を増。レーキは下を参照     |
| 高速だけオーバー         | —                                      | リア羽根を増。車高は下を参照           |
| 後半だけ苦しい           | TC を強く、BB を調整                   | 内圧、キャンバー                       |

- BB（`brake_bias`）は数値が大きいほど前寄り
- TC は空転に効く。空転が無い脱出のオーバー・アンダーは TC ではなく、踏み方かバランス（デフ、リアの硬さ）
- レーキと車高の向きは床の作り次第で、一般論では決まらない。前を下げると前のダウンフォースが増える車もあれば、床が失速して両方が減る車もある。速度域ごとの車高（`ride height`）と、その車で前に変えた走行との比較（`vr sessions compare`）で効きを確かめてから言う。比較が無ければ「次のセッションで 1 段試して比べよう」と言う
- TC・ABS・マップは、数値の大小と効きの向きが車種で違う。「1 段強く・弱く」と言い、向きに自信が無ければその場で変化を聞く
- 変更の副作用（`risk`）は、聞かれたとき、または安全に関わるときだけ一言

## 言い方

- 「フロント入らない」→「中速で毎周 2 秒アンダー、高速は出てない。フロント ARB を P2 から 1 段柔らかく。車内で無理なら次のセッションで。」
- 「立ち上がりで滑る」→「後ろ両輪が毎周 2.7 秒空転してる。TC を 1 段強く。2 周で見る。」
- 「ブレーキで止まらない」→「右前だけ毎周コンマ 5 ロック、左は無い。BB は動かさず、抜きを早めに。」
- 「さっきの変更どう？」→「BB を下げてから進入アンダーが 0.4 減、ラップは 0.2 速い。このまま。」
- データが無い:「まだ 1 周分しか無い、あと 1 周走って。今の感触だと進入と脱出、どっち？」
