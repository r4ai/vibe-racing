# ドライビングアドバイス規範（SF / SGT / F1 / WEC）

走行中のドライバーに「ラインを見直そう」「もっと速く」「集中しよう」と漠然と言わない。
テレメトリ（`vr sessions corners`・`vr sectors`・`vr handling`・`vr car`）から **原因 → 具体操作 → 狙い** を 1 つに絞り、コーナー名と数字を付けて伝える。

## コーナー解析の優先順位（`vr sessions corners`）

1 周だけのミスに飛びつかず、まず `usually lost`（直近周の中央値で常に失っているコーナー）を優先して見る。
同じコーナーでも、**ブレーキ位置より先にペダルの形**を確認する（踏み始めが同じでも、踏み方・抜き方でタイムは大きく変わる）。

### 1. ペダル波形からの診断（ベスト周との比較）

| テレメトリの傾向                                               | 原因                                 | エンジニアの具体指示                                                                 |
| -------------------------------------------------------------- | ------------------------------------ | ------------------------------------------------------------------------------------ |
| `pedal peak` が 10% 以上低く、`held at (decel_g)` も 0.1G 低い | 初期踏力不足                         | 「最初の踏みが甘い、ベストは 95% 出てる。踏み始めから素早く強く踏もう。」            |
| `built in` が 10m 以上長く、`decel_g` も 0.1G 低い             | 踏み込みの立ち上がりが遅い           | 「踏み込みが 10m 遅い。ブレーキ開始から一気に最大踏力まで乗せよう。」                |
| `at turn-in`・`released over` が少なく、ボトムも低い           | トレイルの抜きが早くフロント荷重抜け | 「ブレーキを抜くのが早い。曲がり始めまで 30% ほど残してフロントを曲げよう。」        |
| `at turn-in`・`released over` が多く、ボトムも低い             | ブレーキ引きずりすぎで失速           | 「ブレーキを引きずってボトムが 4 キロ低い。10m 早めに抜いて転がそう。」              |
| `coasting` が 10m 以上長く、ボトムも速くない                   | ブレーキからアクセルへの持ち替え遅延 | 「空走が 10m 長い。ブレーキを離したら間を空けずアクセルに乗せよう。」                |
| `throttle picked up` が 10m 以上遅く、ボトムは適正             | 立ち上がりのアクセル開け始めが遅い   | 「アクセルの踏み始めが 10m 遅い。向きが変わった瞬間に早めに乗せよう。」              |
| `to_full_m` が 20m 以上長い                                    | 全開までの踏み増しが慎重すぎる       | 「全開までが 20m 長い。ステアリングが戻り始めたらしっかり踏み切ろう。」              |
| `lifts` が増え、`countersteer` または `wheelspin` あり         | 焦ったアクセルでリア破綻・空転       | 「立ち上がりでリアが出て戻してる。向きが変わるまで一呼吸待って、穏やかに開けよう。」 |

`pedal peak` が低くても `decel_g` が同じなら ABS や踏力上限が効いているだけなので「もっと踏め」とは言わない。
`lifts` に `countersteer` も `wheelspin` も付いていなければペダルではなくラインの問題の可能性がある。

### 2. 位置・速度・ギアからの診断

| テレメトリの傾向                                         | 原因                               | エンジニアの具体指示                                                                  |
| -------------------------------------------------------- | ---------------------------------- | ------------------------------------------------------------------------------------- |
| `reference_min_throttle == 100` かつ `min_throttle < 95` | 全開区間での不要なリフト           | 「ベストは全開だ。切りすぎずアクセル戻さず行ける。」                                  |
| `brake_m >= +5m` かつ出口・ボトム・アクセルが遅い        | 突っ込みすぎ（オーバースピード）   | 「ブレーキが 10m 奥すぎて脱出が遅れてる。手前から入って向きを変え、早めに開けよう。」 |
| `brake_m <= -5m` かつボトムが低い                        | ブレーキが早い・減速過多           | 「ブレーキが 10m 早い。あと 10m 奥で踏んでボトムを乗せよう。」                        |
| `brake_m` は適正だが `min_kmh <= -3`                     | トレイル過多・舵角過多             | 「ボトムが 4 キロ低い。ブレーキの抜きを少し早めて転がそう。」                         |
| `throttle_m >= +5m` または `exit_kmh <= -3`              | 脱出のアクセルが遅い               | 「出口が 4 キロ遅い。脱出重視で向きが変わったら早めに開けよう。」                     |
| `gear < reference_gear` かつボトムが低い                 | シフトダウンしすぎでエンブレ失速   | 「ベストは 3 速。1 速上でボトムを転がそう。」                                         |
| `gear > reference_gear` かつ出口・アクセルが遅い         | ギアが高すぎて立ち上がり加速が鈍い | 「ベストは 2 速。1 速落として立ち上がりを稼ごう。」                                   |

長いストレートにつながるコーナー（鈴鹿のスプーン・シケイン・デグナー 2、スパのラ・ソース・ブランシモン等）は、進入の 1m より出口の 3 km/h がタイムに大きく効く。

### 3. シフトと回転管理（`changes up` / `changes down`）

- `pull crossover` は直線全開加速から求めた推定交点（シフト時間は未考慮）。命令せず「3 速はもう少し引っ張って次の周で比べよう」と提案する。言い切るのはベスト周のシフト回転と比べられるときだけ
- `limiter` の `on it` が長ければ「リミッターに当たってる、少し早めに上げよう」
- `changes down past it` があれば「ヘアピンの 2 速は落とすのが早い、もう少し速度を落としてから」

## 挙動・タイヤ・路面との連動（`vr handling` / `vr car` / `vr brief`）

| 状況                                   | 運転での一手                                                   | 車内調整（あれば）           |
| -------------------------------------- | -------------------------------------------------------------- | ---------------------------- |
| 進入アンダー・前輪ロック               | 初期踏力を少し抑え、トレイルを丁寧に抜いて旋回にグリップを回す | BB を 1 段後ろ               |
| 進入オーバー・リアロック               | シフトダウンを少し遅らせ、直線で減速を終わらせる               | BB を 1 段前                 |
| 中盤アンダー                           | 進入を 3〜5 km/h 抑えてフロント荷重を残し、クリップを取る      | フロント ARB 1 段柔らかく    |
| 脱出オーバー・空転                     | 向きが変わるまで一呼吸待つ、または立ち上がりでショートシフト   | トラコン 1 段強く            |
| スティント後半のタレ（fade > 0.1s/周） | 舵角を減らし、立ち上がりはショートシフトと丁寧なスロットル     | トラコン 1 段強く・BB 微調整 |
| ウェット・雨の増え始め                 | 縁石と白線を避け、ブレーキは直線で終わらせて脱出を慎重に       | トラコン 1 段強く・ABS 強め  |
| アウトラップ（冷間タイヤ）             | 最初の 1〜2 コーナーは進入を抑え、ブレーキと加速で熱を入れる   | —                            |

## レースクラフト（攻めどころ・守りどころ・トラフィック）

- **攻めどころ**: `vr sectors` の `loses to you most`（自分が相手より速い区間）を起点に、その次のストレートやブレーキングゾーンを仕掛けどころとして 1 つに指定する
- **守りどころ**: `gains on you most`（相手が速い区間）の出口と、その次のブレーキングのイン側を守るよう伝える
- **OTS / P2P**: 残量（`brief` の `P2P/OTS`）が相手より有利なら「次のストレートで OTS 使って並べよう」、相手が `ON now` ならイン側警戒を添える
- **マルチクラスのトラフィック**: 処理に時間がかかる中高速コーナーで並ばず、立ち上がり重視でストレートで抜く意識を促す

## 燃費セーブ（WEC / F1 / Super GT 式）

「燃費を抑えて」だけで終えず、**目標消費（残燃料 ÷ 残り周回、L/周）** と具体的な走法を必ずセットで伝える。

- **リフト＆コースト（リフコ）**: 「長いストレートエンドで 50〜100m 手前からアクセルを戻して転がそう。目標は 1 周 2.5 リッター。」
- **ショートシフト**: 「コーナー立ち上がりで早めにシフトアップして燃費を稼ごう。」
- **スリップ活用**: 「前のスリップを使ってストレートで燃料を浮かせよう。」
