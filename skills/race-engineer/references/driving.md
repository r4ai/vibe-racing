# ドライビングアドバイス規範（SF / SGT / F1 / WEC）

走行中のドライバーに「ラインを見直そう」「もっと速く」と漠然と言わない。テレメトリ（`vr sessions corners` / `vr sectors` / `vr handling` / `vr car`）から**原因 → 具体操作 → 狙い**を一つに絞って伝える。

## コーナー波形からの診断（`vr sessions corners`）

| テレメトリの傾向                                         | 原因                               | エンジニアの具体指示                                                                  |
| -------------------------------------------------------- | ---------------------------------- | ------------------------------------------------------------------------------------- |
| `reference_min_throttle == 100` かつ `min_throttle < 95` | 全開区間でのアクセル戻し           | 「ベストは全開だ、舵を切りすぎず全開で通せる。」                                      |
| `brake_m >= +5m` かつ出口・ボトムが遅い                  | 突っ込みすぎ（オーバースピード）   | 「ブレーキが 10m 奥すぎて脱出が遅れてる。手前から入って向きを変え、早めに開けよう。」 |
| `brake_m <= -5m` かつボトムが低い                        | ブレーキが早い・減速しすぎ         | 「ブレーキが 10m 早い。あと 10m 奥で踏んでボトムを乗せよう。」                        |
| `brake_m` は適正だが `min_kmh <= -3`                     | トレイルの抜きが遅い・舵角過多     | 「ボトムが 4 キロ低い。ブレーキの抜きを早めてフロント荷重を残しつつ転がそう。」       |
| `throttle_m >= +5m` または `exit_kmh <= -3`              | 脱出のアクセルが遅い               | 「出口が 4 キロ遅い。向きが変わった瞬間に早めに開けてストレートに繋げよう。」         |
| `gear < reference_gear` かつボトムが低い                 | シフトダウンしすぎでエンブレ・失速 | 「ベストは 3 速。1 速上でボトムを転がそう。」                                         |
| `gear > reference_gear` かつ出口が遅い                   | ギアが高すぎて立ち上がり加速が鈍い | 「ベストは 2 速。1 速落として立ち上がりを稼ごう。」                                   |

長いストレートにつながるコーナー（鈴鹿のスプーン・シケイン・デグナー 2、スパのラ・ソース・ブランシモン等）は、進入の 1m より出口の 3 km/h がタイムに大きく効く。

## 挙動・タイヤ・路面との組み合わせ

| 状況（`vr handling` / `vr car` / `vr brief`） | 運転での一手                                                      | 車内調整（あれば）           |
| --------------------------------------------- | ----------------------------------------------------------------- | ---------------------------- |
| 進入アンダー・前輪ロック                      | 初期踏力を少し抑え、トレイルを丁寧に抜いて旋回にグリップを回す    | BB を 0.5 後ろ               |
| 進入オーバー・リアロック                      | シフトダウンを少し遅らせ、直線で減速を終わらせる                  | BB を 0.5〜1.0 前            |
| 中盤アンダー                                  | 進入を 3〜5 km/h 抑えてフロントに荷重を残し、クリップを確実に取る | フロント ARB 1 段柔らかく    |
| 脱出オーバー・空転                            | 向きが変わるまでワンテンポ待つ、または立ち上がりでショートシフト  | トラコン 1 段強く            |
| スティント後半のタイヤタレ（fade > 0.1s/lap） | 舵角を減らし、立ち上がりはショートシフトと丁寧なスロットルで保護  | トラコン 1 段強く・BB 微調整 |
| ウェット・雨の降り始め                        | 縁石と白線を避け、ブレーキは直線で終わらせて脱出を慎重に          | トラコン 1 段強く・ABS 強め  |
| アウトラップ（冷間タイヤ）                    | 最初の 1〜2 コーナーは進入を抑え、ブレーキとトラクションで温める  | —                            |

## 燃費セーブ（WEC / F1 / Super GT 式）

燃料がわずかに足りないときは「抑えて」だけで終えず、目標消費（残燃料 ÷ 残り周回、L/周）と走法をセットで伝える。

- **リフト＆コースト**: 「長いストレートエンドで 50〜100m 手前でアクセルを戻して転がそう。目標は 1 周 2.5 リッター。」
- **ショートシフト**: 「コーナー立ち上がりで早めにシフトアップして燃費を稼ごう。」
- **スリップ活用**: 「前のスリップを使ってストレートで燃料を浮かせよう。」
