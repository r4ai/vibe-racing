# vr コマンドリファレンス

## 共通オプション

| オプション                                           | 内容                                                   |
| ---------------------------------------------------- | ------------------------------------------------------ |
| `-f, --format text\|json`                            | 既定 `text`（簡潔テキスト）。`json` は 1 オブジェクト  |
| `--server <URL>` / `VR_SERVER`                       | 問い合わせ先の `vr serve`。既定は自動検出              |
| `--game iracing\|assetto\|ac-udp\|replay\|synthetic` | データソースを明示（サーバーを使わずプロセス内で処理） |
| `--host <PC[:port]>`                                 | `ac-udp` の読み先。既定 `127.0.0.1`（9996 番）         |
| `--file <ndjson>` / `--speed <x>` / `--until <秒>`   | 記録の再生、再生速度、停止するセッション時刻           |

## データの取り方

1. `--game` / `--file` 指定なし: 起動中の `vr serve`（履歴あり）
2. サーバー無し: iRacing、無ければ Assetto Corsa の共有メモリを 1 回読む（`history=unavailable`）
3. `--file` / `--game synthetic`: 記録・デモレースを最後（または `--until`）まで流して回答

## コマンド

| コマンド                                                             | 内容                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| -------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `vr serve [--port 47800] [--record out.ndjson] [--record-hz 10]`     | 常駐コレクターと `127.0.0.1` の HTTP API。ゲーム再起動時は自動再接続。`--if-needed` は起動済みなら何もしない、`--no-sessions` はセッションを残さない、`--no-import` はゲームの記録ファイルを自動で取り込まない                                                                                                                                                                                                                                                            |
| `vr brief`                                                           | 無線回答用サマリ（セッション、自車、前後、近くの車、燃料、天気と雨の傾向・止むまでの目安、タイヤが分かれたかウェットのときはクラスのタイヤごとの台数とペース、直近イベント 5 件）                                                                                                                                                                                                                                                                                         |
| `vr standings [--top N] [--around N] [--overall]`                    | 順位表。マルチクラスでは既定でクラス内                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `vr gap [--car N] [--window 秒]`                                     | 前後・指定車との差、コース上の近くの車（`rel_s` 正 = 前）                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `vr fuel`                                                            | 燃料残、1 周燃費、残り周回、ゴールまでの必要量                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `vr strategy`                                                        | タイムの落ち、ストップの損失、止まる周の案、復帰位置、前後の車とのアンダーカット・オーバーカット、他車の速いタイヤに替えて元が取れるか（`strategy.md`）                                                                                                                                                                                                                                                                                                                   |
| `vr laps [--car N] [--last 10]`                                      | ラップ履歴。`pit` はピットレーン通過、`caution` は黄旗中（どちらも平均から除外）                                                                                                                                                                                                                                                                                                                                                                                          |
| `vr sectors [--car N]`                                               | 自車・前後・トップのセクタータイム（前周・ベスト・今の周）、今の周のここまでのベスト区間との差、相手との差、失った／稼いだ場所（既知のコースはコーナー名付き）。`--car ahead` / `--car behind` で前後の車と比べる。各区間のコーナー名、ベスト区間の合計（ideal lap）、前後・トップがどの区間で自分より速い・遅いか。位置から計算した値                                                                                                                                    |
| `vr say <話題>`                                                      | 決まった質問への結論を、日本語の無線の言い方で 1 つ（`losing` は走行中のセッションに 2 周分の記録があれば、いちばん失うコーナーとブレーキ・最低速度・アクセルの直し方）。話題は `status position ahead behind leader pace ahead-lap leader-lap lap sectors losing fuel fuel-laps left flags weather damage tyres tyre-temps forecast`                                                                                                                                     |
| `vr forecast`                                                        | このままのペースでの着順、各車とのゴールでの差、出会う周。ピットは数えない                                                                                                                                                                                                                                                                                                                                                                                                |
| `vr sessions corners [セッション] [--lap N] [--against N]`           | 直前の周を自己ベストとコーナーごとに比較（ブレーキ開始と最低速度点の何 m 手前か・進入速度・最低速度・ギア・アクセルの戻し方・出口）、いつも失う場所、最高速と速度域別の最低速度の差。鈴鹿・スパはコーナー名（スプーン、S字…）で全コーナー                                                                                                                                                                                                                                 |
| `vr events [--since SEQ] [--limit 30]`                               | フラッグ、順位変動、ピット、インシデント、ラップ、自己ベスト、燃料不足、損傷、路面の変化、車内設定の変更、作戦の助言（`strategy`）。`last_seq` で差分取得                                                                                                                                                                                                                                                                                                                 |
| `vr car`                                                             | 自車の詳細。エンジン、タイヤ、ピット作業、損傷、OTS・DRS、車内設定と変更履歴                                                                                                                                                                                                                                                                                                                                                                                              |
| `vr setup`                                                           | ガレージのセットアップ全項目、走行中に変えられる設定                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `vr handling [--last 3]`                                             | アンダー・オーバー・空転・ロックの傾向（秒/周）、場所（既知のコースはコーナー名）、変更案                                                                                                                                                                                                                                                                                                                                                                                 |
| `vr channels [語...]`                                                | ゲームが出す全変数（名前・値・単位・説明）。語は名前・単位・説明の部分一致（AND）                                                                                                                                                                                                                                                                                                                                                                                         |
| `vr info [パス]`                                                     | ゲーム自身のセッション情報。例 `WeekendInfo/TrackNumTurns`、`DriverInfo/Drivers/0`（iRacing）、`static/carModel`・`results/sessions/0`（Assetto Corsa）                                                                                                                                                                                                                                                                                                                   |
| `vr sessions list [--limit N] [--track 語] [--car 語] [--kind 種別]` | 過去のセッション（新しい順）                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `vr sessions show\|setup <指定>`                                     | 結果・ラップ・イベント／セットアップ。指定は ID、ID の先頭、`last`、番号（1 が最新）                                                                                                                                                                                                                                                                                                                                                                                      |
| `vr query "SQL"` / `vr query --schema`                               | 保存した全セッションに SQL（DuckDB）で何でも聞く。表は sessions・laps（全車）・events・corners（周ごとのコーナー）・telemetry（自車の毎フレーム）・cars（全車 10 Hz）・car_corners（全車のコーナータイム）・brakes（自車の 60 Hz のブレーキ位置）。他車との比較は corner_field（コーナーごとの最速との差と誰か）。まず集計済みの lap_stats（車ごとのベスト・安定度・終盤の落ち）と corner_stats（コーナーごとのロス合計・ベスト・全開か）を使う。読み取り専用、200 行まで |
| `vr sessions lake`                                                   | 以前に残した周から corners の表を作る                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `vr sessions compare <A> <B>`                                        | ラップ・燃費・セットアップの差                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `vr sessions analyse [指定]`                                         | セットアップの分析: バランス、四輪の実測、ガレージの打ち手、車内の変更の結果、別のセットアップとの比較。省略時は同じ車・コースで実測のある最新の走行                                                                                                                                                                                                                                                                                                                      |
| `vr sessions note <指定> <文>`                                       | メモ（空で削除）                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `vr sessions export <指定> --out x.json`                             | JSON に書き出し                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `vr sessions import <x.ibt>...`                                      | iRacing の記録ファイルを取り込み（自車のデータだけ）                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `vr sessions delete <指定> --yes`                                    | 削除。ドライバーに頼まれても無線からは実行しない                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `vr watch`                                                           | イベントのストリーム（サーバーがあれば SSE）                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `vr live [--hz N]`                                                   | 刻々と変わる値を数値だけで（速度・ペダル・差・燃料・旗など）。`--hz` で毎秒 N 行の JSON を流し続ける                                                                                                                                                                                                                                                                                                                                                                      |
| `vr snapshot`                                                        | 正規化テレメトリ 1 フレーム全量（JSON）                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `vr record --out x.ndjson [--hz 10]`                                 | 記録のみ                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `vr doctor`                                                          | ゲーム接続・サーバー・スキル導入の診断                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `vr skill install [--target claude\|codex\|all] [--project]`         | スキルを Claude Code / Codex に導入                                                                                                                                                                                                                                                                                                                                                                                                                                       |

終了コード: `0` 成功、`3` ゲーム未接続・データ無し、`4` 対象（車番など）無し、`1` その他。

## JSON の主なフィールド

共通 `meta`: `game`, `source`（`live|oneshot|replay|synthetic`）, `connected`, `age_ms`, `history`, `session_time_s`, `capabilities`。

`brief`:

- `session`: `kind`（`practice|qualify|warmup|race`）, `phase`, `track`, `lap`, `laps_total`, `laps_remaining`, `time_remaining_s`, `flags[]`
- `player`: `car{number,driver,class_name,position,class_position}`, `cars_total`, `cars_in_class`, `last_lap_s`, `best_lap_s`, `avg_lap_s`, `incidents`, `on_pit_road`, `live_position`（走行順。レースだけ）
- `ahead` / `behind`: `car`, `gap_s`（正の秒）, `laps`（周回差）, `mode`（`race_time|track_progress|best_lap`）, `trend_s_per_lap`（負 = 縮小）, `their_last_lap_s`, `last_lap_delta_s`（負 = 相手が速い）, `on_pit_road`, `live_s`（今この瞬間の差）, `live_change_s`（1 周前からの変化）, `live_ahead`（コース上で前にいるか）
- `leader`: トップ（前の車がトップのときは無し）。`running_ahead` / `running_behind`: 走行順の前後（公式の順位と違うときだけ）
- `nearby[]`: `car`, `rel_s`（正 = 前）, `same_class`, `lap_diff`（正 = 相手が周回で前）
- `fuel`: `fuel_l`, `capacity_l`, `per_lap_l`, `basis`（`history|instant|none`）, `laps_sampled`, `laps_of_fuel`, `laps_to_finish`, `to_finish_l`（正 = 不足、負 = 余り）, `add_with_margin_l`, `last_lap_on_fuel`
- `recent_events[]`: `seq`, `session_time_s`, `type`, `text`
- `car`: 自車の詳細（`vr car` の `car` と同じ）

`car`: `car{tyres{lf,rf,lr,rr}{cold_kpa,hot_kpa,temp_c[外,中,内],tread[外,中,内]},tyre_compound,warnings[],pit{...},controls[]{id,value},p2p_count,p2p_active,drs_active,battery_pct,...}`, `water_temp_c`, `oil_temp_c`, `adjustments[]`。

`handling`: `ready`, `laps_sampled`, `mean{understeer{entry,mid,exit},oversteer{...},wheelspin_s,rear_lock_s,abs_s,max_slip_deg}`, `laps[]`, `zones[]`, `controls[]`, `adjustments[]`, `advice[]{place(in_car|pit|garage),target,current,change,reason,risk}`。

`strategy`: `missing[]`, `lap`, `laps_total`, `stops_done`, `tyre_age`, `fade{own_s_per_lap,field_s_per_lap,used_s_per_lap,basis,fresh_gain_s}`, `pit_loss{seconds,basis,stops}`, `fuel_window[開始,終了]`, `fuel_to_end`, `plans[]{stops[],behind_best_s}`, `rejoin_now{position,ahead,ahead_s,behind,behind_s,traffic}`, `rivals[]{car,gap_s,net_gap_s,stops,tyre_age,undercut_gain_s[],undercut_laps,threat_gain_s[],threat_laps,overcut_laps,...}`, `calls[]{call,...}`。

`live`: `values{キー: 数値}`。キーの一覧と単位は `vr live`。

`sessions analyse`: `behaviour`, `chassis{lock_s,spin_s,front_brake,ride[],loaded_c,pressure_kpa,dampers,...}`, `findings[]{area,evidence,options[]{change,items[],risk}}`, `experiments[]`, `comparisons[]`。

`sectors`: `basis`（`game_lines|thirds|none`）, `starts[]`, `rows[]{car,role,last_lap_s,lap,last[],best[],current[]}`, `versus`, `delta[]`（正 = 自車が遅い）, `losses[]` / `gains[]{from,to,from_m,to_m,sector,lost_s}`。分からない値は `null`。

`forecast`: `laps_left`, `position`, `finish`, `pace_s`, `cars[]{car,gap_s,pace_s,slower_s,at_flag_s,meets_in_laps}`（`gap_s`・`at_flag_s` は正 = 前にいる、`slower_s` は正 = 相手が遅い）。

`sessions corners`: `lap`, `time_s`, `reference_lap`, `reference_s`, `length_m`, `corners[]{number,name?,from,apex,to,loss_s,brake_m,min_kmh,throttle_m,exit_kmh,reference_min_kmh,brake_before_m?,reference_brake_before_m?,gear?,reference_gear?,entry_kmh,reference_entry_kmh,min_throttle,reference_min_throttle}`, `usual_s[]`, `usual_laps`, `speeds{top_kmh,top,slow,medium,fast}`。

`say`: `topic`, `text`。

`setup`: `setup{name,modified,passed_tech,items[]{path,value},unavailable[]}`（`unavailable` はゲームが値を出さない項目）, `controls[]`, `adjustments[]`。

## HTTP API（`vr serve`）

`GET /v1/health`, `/v1/brief`, `/v1/standings?top=&around=&class_only=`, `/v1/gaps?car=&window_s=`, `/v1/fuel`, `/v1/strategy`, `/v1/forecast`, `/v1/live`, `/v1/live/stream?hz=`（SSE、event 名 `live`）, `/v1/laps?car=&last=`, `/v1/sectors?car=`, `/v1/events?since=&limit=`, `/v1/events/stream`（SSE、event 名 `race`）, `/v1/snapshot`, `/v1/car`, `/v1/setup`, `/v1/handling?last=`, `/v1/channels?filter=`, `/v1/info?path=`, `/v1/sessions`, `/v1/sessions/{id}`, `/v1/sessions/{id}/analysis`, `/v1/sessions/{id}/laps`。
レスポンスは `-f json` と同じ。
